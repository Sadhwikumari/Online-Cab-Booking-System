Online Cab Booking System

About the Project

The Online Cab Booking System is a web-based application designed to make cab booking easy and convenient for users.

Features

- User Registration and Login
- Book a Ride
- Booking Confirmation
- View My Rides
- Responsive User Interface

Technologies Used

- HTML
- CSS
- JavaScript
- Java
- DBMS

Project Purpose

This project helps me improve my web development, programming, and database management skills.
